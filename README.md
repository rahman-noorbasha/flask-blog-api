# Flask Social Platform

A full-stack social blogging platform built with Flask, PostgreSQL, SQLAlchemy, HTML, CSS, JavaScript, and Flask-Login.  
This project allows users to create posts, interact with other users, manage profiles, receive notifications, verify email accounts, and use a production-ready persistent database.

## About the Project

Flask Social Platform is a full-stack web application created as a fresher-level portfolio project to demonstrate practical backend and frontend development skills.

The project started as a simple blog application and was gradually upgraded into a social platform with authentication, post management, likes, comments, bookmarks, followers, notifications, profile management, email verification, forgot password functionality, and PostgreSQL database integration.

This project helped me understand how real-world web applications are structured, developed, debugged, deployed, and maintained.

---

## Features

### User Authentication
- User registration
- User login and logout
- Password hashing for secure authentication
- Email verification
- Forgot password and reset password flow
- Protected routes using Flask-Login

### Posts
- Create posts
- Edit posts
- Delete posts
- Add image or file attachments
- View individual posts
- Share post links
- Dashboard for managing personal posts
- Feed page for viewing all users' posts

### Social Features
- Like and unlike posts
- Add comments
- Edit comments
- Delete comments
- Post creator can delete comments on their posts
- Bookmark and save posts
- View saved posts
- Follow and unfollow users
- Personalized feed support

### User Profile
- Public user profile page
- Profile picture upload
- Edit profile details
- Bio, GitHub, LinkedIn, and location fields
- Followers and following count
- User post listing

### Notifications
- Notification system for user interactions
- Notifications for follow, like, comment, and share actions
- Mark notifications as read
- Clear individual notifications
- Clear all notifications

### UI Features
- Responsive dashboard
- Dark mode support
- Image preview support
- Clean navigation bar
- Flash messages for user feedback
- Professional UI styling using HTML and CSS

### Database and Deployment
- Migrated from SQLite to PostgreSQL
- SQLAlchemy ORM integration
- Persistent database on Render
- Environment variables for sensitive data
- Deployed on Render using Gunicorn
